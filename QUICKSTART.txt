   Complete offline AI system for solving NLP exam questions

   2. Extract model weights from data/gguf_model.zip

   ollama serve                    # Start Ollama (keep running)

   python exam_solver.py "Your question here"   # Single question
   python exam_solver_pipeline.py exam_image.jpg   # From image

📋 CHECKLIST BEFORE RUNNING:

   □ ~20 GB free disk space (for conversion)

🔧 TROUBLESHOOTING:

   Problem: "convert_to_gguf.py not found"
   Solution: Make sure you're in the NLP/ directory

   Problem: "Out of memory during conversion"
   Solution: Ensure ~20 GB free disk space, close other apps

   Problem: "Ollama command not recognized"
   Solution: Restart PowerShell after install, or run: .\install.ps1

   Problem: "GGUF file too small (< 3 GB)"
   Solution: Conversion incomplete, run: python convert_to_gguf.py --force
