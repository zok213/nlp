# Architecture Decision Records

This directory stores Architecture Decision Records (ADRs) for the project.

## What is an ADR?

An ADR documents an important architectural decision made during the project. It includes:

- **Context**: What problem is being addressed?
- **Decision**: What decision was made?
- **Consequences**: What are the results of this decision?

## Creating a New ADR

1. Copy the template (`template.md`) to a new file named `YYYY-MM-DD-decision-title.md`
2. Fill in the context, decision, and consequences
3. Add it to this directory and reference it in your documentation
